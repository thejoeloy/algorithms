# Algorithms and Data Structures
This repo contains a variety of implementations of algorithms in C. The implementations are generally made to be as generic as possible. All of the algorithms and data structures in this repo are based on the CLRS textbook. The style of code is made to match the psuedocode and interfaces described in the textbook as well as possible. 

- Arrays
- Linked Lists
- Binary Heaps
- Binary Trees
- Hashing Data Structures
- Sorting Algorithms
- String Algorithms
