# Linked List
This file contains a C implementation of a generic linked list. This 
function uses dynamically allocated memory. 

## Operations Supported
- BuildLinkedList : Creates an empty linked list which can store values of 
size elemSize
- CreateNode : A function used to create data to be stored into the node 
of a linked list. 
- Traverse : Prints out the elements contained in the linked list. 
- GetAt : Prints out the element at index i in the linked list.
- InsertFirst : Inserts an element into the front of the linked list
- DeleteFirst : Deletes the first element in the linked list.
- InsertLast : Inserts an element into the end of the linked list.
- DeleteLast : Deletes the last element in the linked list.
- InsertAt : Inserts a node at index i in the linked list. 
- DeleteAt : Deletes the node at index i of the linked list. 
- DeleteLinkedList : Deletes all of the memory associated with the linked 
list.
