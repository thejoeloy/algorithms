# Queue
Contains a C implementation of a queue, which implements a LIFO 
interaface. The implementation is generic and supports arbitrary data 
types. For brevity, I have only included comparison functions for the 
standard data types in C, but the implementation is readily amenable to 
support custom data types. The implementation also allocates memory 
dynamically. This implementation is of a static queue, meaning that the 
queue cannot be resized once it has been declared.
